# latebird-email

Images for the Late Bird Sessions artist emails, served by GitHub Pages at
`https://mattiasisa.github.io/latebird-email/images/<file name>`.

## Folder layout
- `images/` holds the shared images used by every email (`lb-sky.jpg`, `lb-stars.png`, icons, bird, burst, wordmark).
- `images/season-1/`, `images/season-2/` and so on hold each season's artist hero images (`lb-hero-<artist-slug>.jpg`).
- New heroes go straight into the season folder.
- The first four heroes (Slug Mass, Cristoffer, Gisela, Rasmus) also still sit loose in `images/`, because emails already sent point at them. Do not delete or rename those.
